# Pattern: more than one sentence

**First seen:** iteration 3

**What happens:** the answer is rejected because more than one sentence.

**Example:** `Assess common hazards in a metal workshop and record the required controls.
Refer to the workshop handbook for further detail.`

**Proposed rule:** Write exactly one sentence on one line, with no list formatting.

## Evidence

- Iteration 3: 2 occurrence(s).

- Iteration 4: recurred 2 time(s). Still unresolved.
